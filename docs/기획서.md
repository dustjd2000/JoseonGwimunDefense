# 조선귀문디펜스 — 기획서 (v0.1)

> 제목: **「조선귀문디펜스」** (패키지명 `com.dustjd.joseongwimundefense`)
> 장르: 2D 성벽 디펜스 + 성장형 RPG 요소
> 플랫폼: Android (Google Play) 우선, iOS는 출시 후 검토
> 엔진: Unity 6000.6.4f1 (URP 2D), C#
> 작성일: 2026-10-04

---

## 1. 한 줄 소개

**북방의 귀문(鬼門)이 열려 쏟아져 내려오는 요괴들을, 조선의 성벽 위에서 궁수·포수·신기전·무녀를 지휘해 막아내는 세로형 성벽 디펜스.**

## 2. 컨셉

### 2.1 세계관
- 시대: 조선 중기를 모티프로 한 가상의 조선. 실존 인물은 직접 쓰지 않고 이름과 설정을 각색합니다(역사 왜곡 논란과 퍼블리시티 리스크를 피하려는 것).
- 사건: 백두산 너머에 봉인되어 있던 **귀문**이 열리면서 한국 설화 속 요괴들이 남쪽으로 내려옵니다.
- 플레이어: 조정이 새로 세운 요괴 토벌 기구 **「진요청(鎭妖廳)」**의 도원수가 되어 팔도의 성을 하나씩 지켜내고, 마지막으로 한양 도성을 지킵니다.

### 2.2 차별점
| 항목 | 내용 |
|---|---|
| 소재 | 서양 판타지나 중국풍이 아닌 **한국 설화 요괴**(도깨비, 구미호, 불가사리, 이무기 등) |
| 무기 | 신기전·화차·비격진천뢰·편전처럼 **실존한 조선 무기**를 스킬로 재해석 |
| 비주얼 | 민화·단청 색감(오방색)과 먹선으로 그린 2D 일러스트 |
| 사운드 | 국악기(대취타, 장구, 태평소)와 현대 비트를 섞은 BGM |

### 2.3 타깃
- 1차: 10~40대 한국 캐주얼·미드코어 유저(Grow Castle, 운빨존많겜 같은 게임을 하는 층)
- 2차: K-컬처, 한국 설화에 관심 있는 해외 유저(영어 현지화)

## 3. 핵심 게임플레이

### 3.1 화면 구성 (세로 모드)
```
┌─────────────────┐
│  웨이브 3/10  ⏸  │  ← 상단 HUD
│                 │
│   👹  👹   👺    │  ← 요괴가 위에서 아래로 진군
│      👹    👹    │
│                 │
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │  ← 성벽 (HP 바)
│ [궁][포][신][무][궁] │  ← 성벽 위 유닛 슬롯 5칸
│  ⚡스킬1 ⚡스킬2    │  ← 사기 게이지 + 액티브 스킬
└─────────────────┘
```
- 한 손으로 플레이할 수 있도록 **세로 화면**을 씁니다.
- 요괴는 화면 위에서 내려와 성벽에 닿으면 공격합니다. 성벽 HP가 0이 되면 패배입니다.

### 3.2 전투 루프
1. **출진 준비**: 성벽 슬롯(처음 3칸, 최대 7칸)에 유닛을 배치합니다.
2. **웨이브 진행**: 유닛은 자동으로 공격합니다. 플레이어는 **사기(士氣) 게이지**를 써서 액티브 스킬을 터치로 발동합니다.
3. **웨이브 사이**: 전투에서 얻은 **엽전**으로 유닛과 성벽을 임시 강화합니다. 이 강화는 해당 스테이지에서만 유지됩니다(로그라이트 요소).
4. **보스 웨이브**: 스테이지의 마지막 웨이브에는 보스가 나옵니다.
5. **결과**: 별 1~3개(남은 성벽 HP 기준)를 받고 영구 재화를 획득합니다.

### 3.3 메타(성장) 루프
```
스테이지 클리어 → 재화(은자·명패) 획득 → 유닛 영구 강화 / 신규 유닛 해금 / 성벽 증축
       ↑                                                    ↓
       └──────────── 더 어려운 스테이지 도전 ←───────────────┘
```

## 4. 콘텐츠

### 4.1 아군 유닛 (성벽 위 배치)
| 유닛 | 역할 | 특징 |
|---|---|---|
| 궁수 (편전) | 단일 딜러 | 공격 속도가 빠르고 가장 가까운 적을 노림 |
| 포수 (조총) | 관통 | 직선상의 적 여러 마리를 관통 |
| 화차병 (신기전) | 광역 | 느리지만 범위 폭발 |
| 총통수 | 대형 특효 | 탱커·보스에게 추가 피해 |
| 무녀 | 서포터 | 주변 유닛 공격력 버프, 부적 결계로 적 둔화 |
| 퇴마사 | 특수 | 영체(靈體) 요괴에게 특효, 일반 공격은 약함 |
| 승병 | 저지 | 성벽 앞으로 나가 근접전으로 적을 붙잡음 |

**액티브 스킬 (사기 게이지 소모)**
- 신기전 일제사격: 지정한 범위에 화살비
- 비격진천뢰: 시간차로 터지는 대형 폭탄
- 성문 보수: 성벽 HP 회복
- 대취타: 일정 시간 아군 전체 공격 속도 증가

### 4.2 요괴 (적)
| 요괴 | 유형 | 특징 |
|---|---|---|
| 도깨비 | 기본 근접 | 무리 지어 다니는 기본 적 |
| 창귀 | 고속 | 빠르게 달려와 성벽에 붙음 |
| 그슨대 | 비행·영체 | 공중 유닛. 일부 유닛만 공격 가능 |
| 불가사리 | 탱커 | 쇠를 먹어 성벽 방어력을 깎음 |
| 구미호 | 원거리 | 여우불로 성벽 위 유닛을 직접 공격 |
| 두억시니 | 분열 | 처치하면 작은 개체 여러 마리로 분열 |
| 어둑시니 | 은신 | 일정 거리 안에 들어올 때까지 보이지 않음 |

**보스**: 대왕 불가사리(1장), 장산범(2장), 구미호 여왕(4장), 이무기(최종장) 등

### 4.3 스테이지 구성 — 팔도 순회
| 장 | 지역 | 대표 성 | 신규 요소 |
|---|---|---|---|
| 1 | 함경도 | 경성 | 튜토리얼, 기본 요괴 |
| 2 | 평안도 | 의주성 | 고속형 등장 |
| 3 | 황해도 | 해주성 | 비행형 등장 |
| 4 | 강원도 | 원주 | 원거리형, 지형(안개) |
| 5 | 경상도 | 동래성 | 분열형 |
| 6 | 전라도 | 전주성 | 은신형 |
| 7 | 충청도 | 공산성 | 복합 웨이브 |
| 8 | 경기도 | 수원 화성 → 한양 도성 | 최종 보스 |

- 장마다 10스테이지, 총 80스테이지로 출시합니다.
- 클리어 후 콘텐츠: **무한 모드(귀문 심층)**, 일일 던전, 주간 랭킹.

## 5. 재화와 수익 모델

### 5.1 재화
| 재화 | 획득처 | 사용처 |
|---|---|---|
| 엽전 | 전투 중 처치 보상 | 웨이브 사이 임시 강화 (스테이지가 끝나면 초기화) |
| 은자 | 스테이지 보상 | 유닛·성벽 영구 강화 |
| 명패 | 유닛 중복 획득, 도전 과제 | 유닛 등급 승급 |
| 옥(玉) | 과금, 업적, 이벤트 | 소환, 편의 기능 |

### 5.2 수익 모델 (공정한 F2P 지향)
- **보상형 광고**: 클리어 보상 2배, 패배 시 부활 1회, 일일 무료 소환
- **광고 제거 상품** (1회 구매)
- **스타터 팩**, 월정액(매일 옥 지급)
- **시즌 패스** (무료·유료 트랙)
- 확률형 아이템을 넣는다면 **확률을 공개**합니다(국내 법 의무).
- 강제 전면 광고는 넣지 않습니다.

## 7. 아트 · 사운드 방향
- **아트**: 2D 일러스트. 민화의 평면성과 오방색(청·적·황·백·흑)을 쓰고, 요괴는 먹선을 강하게 그어 공포보다는 해학을 살립니다.
- **해상도 기준**: 1080×1920 세로, Pixel Perfect는 쓰지 않음
- **애니메이션**: 프로토타입은 스프라이트 시트, 이후 Spine 또는 Unity 2D Animation(본 애니메이션)을 검토
- **사운드**: BGM은 국악 퓨전, 효과음은 활시위·화포·징 소리 중심

1. 세로 화면 전투 씬, 성벽 HP

### 10.1 구조 원칙
- **`_Project/` 하위에만 직접 만든 것을 둡니다.** 서드파티 에셋과 섞이지 않고, 폴더 목록 맨 위에 정렬됩니다.
- **데이터와 로직을 분리합니다.** 수치는 `Data/`의 SO 에셋에, 클래스 정의는 `Scripts/Data/`에 둡니다. 밸런스를 바꿀 때 코드를 건드리지 않습니다.
- **Services는 인터페이스 뒤에 숨깁니다.** `IAdService`, `IIAPService` 같은 인터페이스를 두고 에디터에서는 Mock 구현을 씁니다. SDK가 없어도 에디터에서 플레이할 수 있습니다.
- **Assembly Definition 의존 방향**: `Core` ← `Data` ← `Battle` / `Meta` ← `UI`. 역방향 참조는 금지하고, 필요한 경우 이벤트로 통신합니다.
- `.gitkeep` 파일은 빈 폴더를 Git에 올리기 위한 것입니다. Unity는 점(.)으로 시작하는 파일을 무시하므로 `.meta` 파일이 생기지 않습니다.
